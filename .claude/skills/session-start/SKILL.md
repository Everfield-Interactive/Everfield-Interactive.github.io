# Session start

Follow Section 11.2 of `docs/BUILD_GUIDE.md`.

1. Read `CLAUDE.md`, `docs/STATUS.md` and the open items in `docs/QUESTIONS.md`.
2. Work out which workstream this session is. The lead works in the main checkout. A session inside `.claude/worktrees/vfx/` or `.claude/worktrees/legal/` is a sibling, so read its brief in `docs/workstreams/` and merge `main` into its branch first.
3. Read this workstream's inbox in the `workstreams` folder of `EVERFIELD_SOURCE`.
4. Read the guide section for the current phase.
5. Check the tools the phase needs. For Blender work, run a scene query through the Blender connector and confirm that the session lists every skill in the map in Section 9.2.
6. Confirm the current branch. The lead never commits on `main`.
7. Say in two or three lines what this session will do.
8. At the start of a phase, use plan mode and wait for Kiefy to approve the plan.
